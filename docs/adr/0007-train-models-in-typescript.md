# 0007: 機械学習をすべて TypeScript で行い、学習はローカルで実行する

- ステータス: 承認済み
- 日付: 2026-11-23

## 背景

ユーザーの回答を学習に使い、推定の精度を上げていきます。当初は Python で学習する案もありましたが、すべての学習を TypeScript で行うことになりました。

## 決定

- 学習と推論を TypeScript で実装し、共通の計算は 1 つのモジュールにまとめます。
- 学習は本番環境では行わず、開発者のローカルで Node を使って実行します。
- 学習結果のモデルは JSON として出力し、バージョンを付けてリポジトリで管理します。
- Python は使いません。

## 影響

- 学習と推論が同じコードを使うので、計算のずれが起きません。
- 学習の手順は、Turso からデータを取得し、ローカルで学習してモデルを出力し、PR を出してデプロイする流れです。
- ユーザーの回答は、次にモデルを更新するまで推定に反映されません。
- 学習データ（ユーザーの回答）は、公開リポジトリに入れません。
- 大きなニューラルネットワークが必要になった場合は、この方針を見直します。
- `mise.toml` から Python を削除します。
