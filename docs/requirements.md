# 要件

## 概要

質問に答えると、今日のごはんを提案する Web アプリです。はい、どちらでも、いいえの回答から料理ごとの一致度を計算し、上位 3 品を一致度 % 付きで表示します。

- [UI 設計](ui-design.md)
- [ADR](adr/README.md)

## +α機能

- [ ]  好きな料理を登録して、その料理のスコアを上げる
- [ ]  食べたものの履歴を残し、最近食べたものは下げる。これで食生活の偏りを改善する
- [ ]  PFCバランスの表示。1週間分のグラフもあると良い
- [ ]  適当回答の検知：同じ回答がN回続いたら、アキネーター側がブチ切れるセリフを出す
- [ ]  冷蔵庫モード：持っている食材を選ぶと、それで作れる料理を優先する
- [ ]  質問をAIで生成する。最初は固定の質問プールで十分で、後から追加すればいい
